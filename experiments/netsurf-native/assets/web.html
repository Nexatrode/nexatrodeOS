Click the address bar and type an HTTPS URL, then press Enter. Home returns here. Back returns to the previous page.

JavaScript availability is shown in the toolbar. Persistent storage is disabled. This initial fetcher supports GET, external stylesheets, redirects and bounded responses. Complex sites and SVG/WebP images may look incomplete.
