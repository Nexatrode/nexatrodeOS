# Rust target specification

`aarch64-sel4-microkit.json` is based on the seL4 Rust Microkit demo's
[`support/targets`](https://github.com/seL4/rust-microkit-demo/tree/main/support/targets).
It supplies the custom AArch64 target settings and IPC-buffer linker symbol that
Microkit expects. The upstream file is licensed under BSD-2-Clause; see
[`LICENSE-BSD-2-Clause`](LICENSE-BSD-2-Clause).
