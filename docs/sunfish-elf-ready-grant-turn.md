# Once-only ready ELF grant opportunity

IMG_9807 captured the slow case:61 queued-ELF writer calls,43 excluded by pending intent ACK,11 by ready-credit arbitration,6 by TFTP,1 selected. All8 retained end-of-pass checks had fitting buffers. The previously implemented ready loan only marks transaction3 after its own return. It does not apply to ELF, especially when that request returned before its reply queued.

Feature `sunfish-elf-ready-grant-turn` inherits the verified digest reply and existing scheduler. On normal successful queue admission, it marks the **first queued successful ServiceRegistry response** whose live validated request is `kernel/elf_loader`, domain offset0, local service-registry port to modem node0/port9. Matching uses `request_qmi` and the existing QMI/servreg decoders, not a transaction-number guess or any diagnostic capture. Failed admission does not bind. Other names, offsets, failure responses and endpoints cannot bind. A private Session Boolean prevents a later ELF reply inheriting another opportunity in that generation; the transmit record carries the existing private ready marker and normal opaque request/route identity.

The existing ordinary selector and once-per-transmit borrowed-turn latch handle the opportunity. The marker may exist while the request's own return is pending, but normal class3 selection still excludes it until that real return commits. A fitting intent, correct flow/route, no protected TFTP/WRQ work, no ready credit, clear registry cooldown, unused grant/converted-credit loan, and a positive ACK with backing still Advertising are all required. Once advertised, the grant ACK retains its turn. Negative ACKs retain their path. The existing borrowed latch is consumed before the checked callback, including WouldBlock/unwind; another fresh grant cannot resurrect that record's used loan. Normal byte-identical retry, uncertainty quarantine and actual matching completion remain unchanged. Reset constructs a fresh Session and clears the new Boolean.

There is no added writer loop, receive turn, service turn, timer sample, device read, intent, credit or capability. It adds one Session Boolean and reuses existing per-transmit state. The writer selector, FIFO validator and capability boundaries are unchanged; this is a narrow expansion of which live queued reply can qualify for an existing opportunity. Bounded private request decoding adds host work at admission.

Actual Core schedules cover the real17-byte ELF name and non-special transaction77, own return before/after queueing, still-pending own return, successful exact receipt, blocked-write bytes and a second fresh grant, higher-priority credit, already-advertised ACK, missing fit and actual outbound-intent progression, other names/domain offsets/failure responses, a second valid ELF request denied a second loan, bounded follow-up calls, uncertainty/unwind quarantine and reset. Clockless and clock-enabled success both run. Removing the actual binding or disabling its generation limit makes the corresponding functional test fail. The entire parent source is recovered by removing marked blocks/Cargo line; older source proofs strip this child delta before applying their original boundaries.

The panel title becomes **ELF READY GRANT TURN** with the same rows as ELF WRITER DIGEST REPLY.
